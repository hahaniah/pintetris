
Pintetris

This is a good old simple Tetris game I built using HTML, CSS and .JS! I wanted to experiment if I could make functional games using this languages and I think I was sort of sucessful! I'm super new to game dev and coding in general so I started with this simple project. The .JS scripting took too much of my time but it was a great challenge! This project helped me get better at .JS and now I feel more confident using it.

Assets:

I drew the Tetris blocks and all other assets/elements myself including the background and decor etc. I love how it turned out and it made Tetris very cute which is why I named it Pintetris because I took the inspo of the blocks from Pinterest!

How to Play:

-Click Start button so the blocks start to fall and click Pause button if you want to stop the blocks.

-Use the DOWN ARROW key to speed up the fall of the blocks.

-Use the LEFT and RIGHT ARROW key to change the position of the blocks and move them wherever you want!

-Use the UP ARROW key to rotate the blocks to fit them where you want. 

-Your score and levels go up as you play.

-Click Start to play again!

In the near future, I plan to make it more polished and complex so I’d love any suggestions and feedbacks!
